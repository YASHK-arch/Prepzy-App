Sort Subarray with Left and Right Index

Q3. Sort subarray with left and right index

</> ✔ Solved

Problem Description

You are given an array A of integers of length N and two indices B and C.

Your task is to sort the subarray [B, C] within the given array. The rest of the array should remain unchanged.

Problem Constraints

1 ≤ N ≤ 105

0 ≤ A[i] ≤ 109

0 ≤ B ≤ C ≤ N − 1

Input Format

First argument is the array A of length N. The next two arguments are the integers B and C.

Output Format

Return the array after sorting the [B, C] subarray.

Example Input

Input 1:
A = [59, 11, 8, 91, 49, 44, 8]
B = 4
C = 6

Input 2:
A = [50, 40, 30, 20, 10]
B = 0
C = 3

Example Output

Output 1:
[59, 11, 8, 91, 8, 44, 49]

Output 2:
[20, 30, 40, 50, 10]

Example Explanation

Explanation 1:

Initially subarray A[4..6] = [49, 44, 8].
After sorting → [8, 44, 49].
Rest of array remains unchanged.

Explanation 2:

Initially subarray A[0..3] = [50, 40, 30, 20].
After sorting → [20, 30, 40, 50].
Rest of array remains unchanged. 
        
public class Solution {

    public int[] sortSubarray(int[] A, int B, int C) {

        if (B >= C) return A;   // base case

        int mid = (B + C) / 2;

        sortSubarray(A, B, mid);
        sortSubarray(A, mid + 1, C);

        merge(A, B, mid, C);

        return A;
    }

    private void merge(int[] A, int B, int mid, int C) {

        int[] temp = new int[C - B + 1];

        int i = B;
        int j = mid + 1;
        int k = 0;

        while (i <= mid && j <= C) {
            if (A[i] <= A[j]) {
                temp[k++] = A[i++];
            } else {
                temp[k++] = A[j++];
            }
        }

        while (i <= mid) {
            temp[k++] = A[i++];
        }

        while (j <= C) {
            temp[k++] = A[j++];
        }

        // copy back
        for (int p = 0; p < temp.length; p++) {
            A[B + p] = temp[p];
        }
    }
}
