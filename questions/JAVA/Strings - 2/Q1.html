Shortest substring in A containing B

Q1. Window String

</> ✔ Solved

Problem Description

Given a string A and a string B, find the window with minimum length in A, which will contain all the characters in B in linear time complexity.

Note that when the count of a character c in B is x, then the count of c in the minimum window in A should be at least x.

Note:

  • If no such window exists, return an empty string.
  • If multiple windows exist, return the first occurring one.

Problem Constraints

1 ≤ size(A), size(B) ≤ 10⁶

Input Format

  • The first argument is a string A.
  • The second argument is a string B.

Output Format

Return a string denoting the minimum window.

Example Input

Input 1: A = "ADOBECODEBANC", B = "ABC" Input 2: A = "Aa91b", B = "ab"

Example Output

Output 1: "BANC" Output 2: "a91b"

Example Explanation

Explanation 1:

"BANC" is a substring of A which contains all characters of B.

Explanation 2:

"a91b" is the substring of A which contains all characters of B. 

public class Solution {
    public String minWindow(String A, String B) {

        int[] need = new int[256];
        int[] have = new int[256];

        for (char c : B.toCharArray()) need[c]++;

        int needed = B.length();
        int matched = 0;

        int left = 0;
        int bestLen = Integer.MAX_VALUE;
        int bestStart = 0;

        for (int right = 0; right < A.length(); right++) {

            char rChar = A.charAt(right);
            have[rChar]++;

            if (have[rChar] <= need[rChar]) {
                matched++;
            }

            while (matched == needed) {

                int windowLen = right - left + 1;

                if (windowLen < bestLen) {
                    bestLen = windowLen;
                    bestStart = left;
                }

                char lChar = A.charAt(left);
                have[lChar]--;

                if (have[lChar] < need[lChar]) {
                    matched--;
                }

                left++;
            }
        }

        if (bestLen == Integer.MAX_VALUE) return "";

        return A.substring(bestStart, bestStart + bestLen);
    }
}
