Problem Description

Akash likes playing with strings. One day he thought of applying the following operations on the string in the given order:

  • Concatenate the string with itself.
  • Delete all the uppercase letters.
  • Replace each vowel with '#'.

You are given a string A of size N consisting of lowercase and uppercase alphabets. Return the resultant string after applying the above operations.

NOTE: 'a', 'e', 'i', 'o', 'u' are defined as vowels.

Problem Constraints

  • 1 ≤ N ≤ 100000

Input Format

The first argument is a string A of size N.

Output Format

Return the resultant string.

Example Input

Input 1: A = "aeiOUz" Input 2: A = "AbcaZeoB"

Example Output

Output 1: "###z###z" Output 2: "bc###bc###"

Example Explanation

First concatenate the string with itself, then remove uppercase letters, and finally replace vowels with '#'. 

      
public class Solution {
    public String solve(String A) {

        // Step 1: Concatenate string with itself
        StringBuilder str = new StringBuilder();
        str.append(A);
        str.append(A);

        // Step 2: Delete all uppercase letters
        for (int i = 0; i < str.length(); ) {
            char ch = str.charAt(i);

            if (Character.isUpperCase(ch)) {
                str.deleteCharAt(i);
            } else {
                i++;
            }
        }

        // Step 3: Replace vowels with '#'
        for (int i = 0; i < str.length(); i++) {
            char ch = str.charAt(i);

            if (ch == 'a' || ch == 'e' || ch == 'i' ||
                ch == 'o' || ch == 'u') {
                str.setCharAt(i, '#');
            }
        }

        return str.toString();
    }
}
