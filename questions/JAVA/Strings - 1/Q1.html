Q1 – Longest Palindromic Substring

Q1. Longest Palindromic Substring

</> Solved

Problem Description

Given a string A of size N, find and return the longest palindromic substring in A.

A substring of string A is A[i...j] where 0 ≤ i ≤ j < len(A).

Palindrome String

A string which reads the same backwards. More formally, A is a palindrome if reverse(A) = A.

In case of conflict, return the substring which occurs first (with the least starting index).

Problem Constraints

  • 1 ≤ N ≤ 6000

Input Format

The first and only argument is a string A.

Output Format

Return a string denoting the longest palindromic substring of A.

Example Input

Input 1: A = "aaaabaaa" Input 2: A = "abba"

Example Output

Output 1: "aaabaaa" Output 2: "abba"

Example Explanation

The longest palindromic substring in "aaaabaaa" is of length 7: "aaabaaa".

The longest palindromic substring in "abba" is of length 4: "abba". 

      
public class Solution {
    public String longestPalindrome(String A) {
        int n = A.length();

        int start = 0, maxLen = 1; // store best substring

        for (int center = 0; center < n; center++) {

            // ----- odd length palindrome -----
            int l = center - 1, r = center + 1;
            while (l >= 0 && r < n && A.charAt(l) == A.charAt(r)) {
                int len = r - l + 1;
                if (len > maxLen) {
                    maxLen = len;
                    start = l;
                }
                l--;
                r++;
            }

            // ----- even length palindrome -----
            l = center;
            r = center + 1;
            while (l >= 0 && r < n && A.charAt(l) == A.charAt(r)) {
                int len = r - l + 1;
                if (len > maxLen) {
                    maxLen = len;
                    start = l;
                }
                l--;
                r++;
            }
        }

        return A.substring(start, start + maxLen);
    }
}
