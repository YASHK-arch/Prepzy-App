Q3. Pairs with Given Difference

Problem Description

Given a one-dimensional integer array A of size N and an integer B, count all distinct pairs with difference equal to B.

A pair is defined as an integer pair (x, y), where both values exist in the array and |x − y| = B.

Problem Constraints

  • 1 ≤ N ≤ 104
  • 0 ≤ A[i], B ≤ 105

Input Format

First argument is an integer array A.

Second argument is an integer B.

Output Format

Return an integer denoting the count of all distinct pairs with difference equal to B.

Example Input

A = [1, 5, 3, 4, 2] B = 3

Example Output

2

Example Explanation

The pairs with difference 3 are {1, 4} and {5, 2}. Hence, the output is 2. 

      
public class Solution {
    public int solve(int[] A, int B) {
        Arrays.sort(A);
        int i = 0;
        int j = 1;
        int count = 0;

        while (i < A.length && j < A.length) {

            // Avoid same index
            if (i == j) {
                j++;
                continue;
            }

            int diff = A[j] - A[i];

            if (diff == B) {
                int x = A[i];
                int y = A[j];

                // Skip duplicates of x
                while (i < j && A[i] == x) {
                    i++;
                }

                // Skip duplicates of y
                while (j < A.length && A[j] == y) {
                    j++;
                }

                count++;
            }
            else if (diff < B) {
                j++;
            }
            else {
                i++;
            }
        }

        return count;
    }
}
