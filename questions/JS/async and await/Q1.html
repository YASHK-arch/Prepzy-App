Problem Description

Using async await, complete the function nSeries(fileArray, ansArray).

fileArray is an array of file names and ansArray is the output array.

Requirements

  • All files must be read serially
  • Use the provided fetchByPromise(fileName) function
  • Add the content of each file into ansArray
  • After reading all files, append "All files have been read"

Function Signature

async function nSeries(fileArray, ansArray)

Input Format

let ansArray = []; let fileArray = ["FILE 1", "FILE 2"]; nSeries(fileArray, ansArray);

Output Format

ansArray should contain file contents in order, followed by a completion message.

Example Output

ansArray = [ "content : FILE 1", "content : FILE 2", "All files have been read" ]

Example Explanation

Each file is read one by one using await. Once all files are processed, the final message is added.

    <script id="solution" defer>
        async function nSeries(fileArray, ansArray) {
            try {
                for (let i = 0; i < fileArray.length; i++) {
                    let data = await fetchByPromise(fileArray[i]);
                    ansArray.push(data);
                }
                ansArray.push("All files have been read");
            } catch (error) {
                console.log(error);
            }
        }
