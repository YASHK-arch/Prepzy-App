Problem Description

Write a function callbackChain that takes an array of functions as callbacks.

The callbacks should be executed one after another in the order they are provided, with a delay of 500 milliseconds between each execution.

Function Signature

function callbackChain(callbacks)

Input Format

The first and only argument is an array of callback functions.

Output Format

Executes each callback sequentially with a 500ms delay between executions.

Example Input

callbackChain([ () => console.log("First callback"), () => console.log("Second callback"), () => console.log("Third callback") ]);

Example Output

Prints all three messages with a 500ms delay between each

Example Explanation

Each callback is scheduled using setTimeout, ensuring ordered execution with increasing delays.

        function callbackChain(callbacks) {
              for (let i = 0; i < callbacks.length; i++) {
                 setTimeout(function () {
                    callbacks[i]();
                 }, i * 500);
              }
        }
