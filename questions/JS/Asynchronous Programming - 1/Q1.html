Problem Description

Write a function periodicPrinter that takes a callback function and a timeInterval in milliseconds.

The function should use setInterval to repeatedly execute the callback function every specified time interval until explicitly stopped.

Important Note

You must return the intervalId from the function. If not returned, the backend will not be able to clear the interval, resulting in a failed test case.

Function Signature

function periodicPrinter(callback, timeInterval)

Input Format

First argument is a callback function.
Second argument is an integer timeInterval representing milliseconds.

Output Format

Return the intervalId created by setInterval.

Example Input

periodicPrinter(() => { console.log("This is callback"); }, 1000);

Example Output

Prints "This is callback" every 1000ms

Example Explanation

The callback function is executed every 1000 milliseconds. The returned intervalId can later be passed to clearInterval to stop execution.
