Problem Description

Complete the function twoSeries(file1, file2, ansArray), which takes two file names and an array as input.

The files must be read serially using the fetchByPromise(fileName) function.

Requirements

  • Both files must be read one after the other using Promises
  • Add the content of both files into ansArray
  • After reading both files, append the string "All files have been read" to the array

Function Signature

function twoSeries(file1, file2, ansArray)

Example Input

let ansArray = []; twoSeries("FILE 1", "FILE 2", ansArray);

Example Output

ansArray = [ "content : FILE 1", "content : FILE 2", "All files have been read" ]

Example Explanation

The first file is read using a Promise. Once it resolves, the second file is read. After both Promises resolve, the completion message is added to the array.

    <script id="solution" defer>
        function twoSeries(file1, file2, ansArray) {
            fetchByPromise(file1)
              .then(function (data1) {
                  ansArray.push(data1);
                  return fetchByPromise(file2);
              })
              .then(function (data2) {
                  ansArray.push(data2);
                  ansArray.push("All files have been read");
              });
        }
