Problem Description

Write a function convertCurrency that takes an amount, a source currency, and a target currency, and returns a Promise.

The Promise should resolve with the converted amount if the conversion is successful; otherwise, it should reject with an error message.

Function Signature

function convertCurrency(amount, sourceCurrency, targetCurrency)

Requirements

  • Use a Promise to handle currency conversion
  • Resolve with the converted amount if currencies are valid
  • Reject with an error message if any currency is invalid

Example Test Cases

convertCurrency(100, "USD", "EUR") .then(result => console.log(`Converted amount: ${result} EUR`)) .catch(error => console.error(error)); convertCurrency(50, "USD", "JPY") .then(result => console.log(`Converted amount: ${result} JPY`)) .catch(error => console.error(error)); // Expected output: // "Error converting currency: Invalid currency"

Example Explanation

If both source and target currencies exist in the exchange rate table, the Promise resolves with the converted value. Otherwise, the Promise is rejected with an error message. 

      
const exchangeRates = {
    'USD': 1.0,
    'EUR': 0.85,
    'GBP': 0.75,
};

function convertCurrency(amount, sourceCurrency, targetCurrency) {
    return new Promise(function (resolve, reject) {
        if (exchangeRates[sourceCurrency] && exchangeRates[targetCurrency]) {
            let sourceRate = exchangeRates[sourceCurrency];
            let targetRate = exchangeRates[targetCurrency];

            let convertedAmount = amount * (targetRate / sourceRate);
            resolve(convertedAmount);
        } else {
            reject("Error converting currency: Invalid currency");
        }
    });
}
