Problem Statement

Implement an interactive UI that demonstrates event bubbling. The application should contain nested elements: a box inside a container inside the body.

When a user clicks on the box, display the events triggered in the bubbling phase for the box, container, and body.

Problem Description

  • Create an HTML structure: body > div.container > div.box
  • Clicking the innermost box should propagate the event upward
  • Log which element’s event listener is triggered (bubbling order)
  • Display logs inside a #log div

Hints

  • Use addEventListener on body, container, and box
  • Use default bubbling phase (no capture flag)
  • Use event.target to detect clicked element
  • Clear logs before each click

<body>
  <div class="container">
    <div class="box"></div>
  </div>
  <div id="log"></div>

  <script>
    const logDiv = document.getElementById("log");
    const box = document.querySelector(".box");
    const container = document.querySelector(".container");
    const body = document.body;

    function logEvent(name) {
      const p = document.createElement("p");
      p.textContent = `Event triggered on: ${name}`;
      logDiv.appendChild(p);
    }

    body.addEventListener("click", () => {
      logDiv.innerHTML = "";
    }, true);

    box.addEventListener("click", () => {
      logEvent("box");
    });

    container.addEventListener("click", () => {
      logEvent("container");
    });

    body.addEventListener("click", () => {
      logEvent("BODY");
    });
  </script>
</body>

</html>
