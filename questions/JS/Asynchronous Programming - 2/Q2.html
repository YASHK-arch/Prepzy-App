Problem Description

Complete the function nSerialReader(idx, files, ansArray), which reads multiple files serially.

Function Parameters

  • idx – current index (initially 0)
  • files – array of file names
  • ansArray – empty array to store file contents

Requirements

  • All files must be read serially using fetchByCb
  • Add the content of each file to ansArray
  • Prepend each file’s content with "content -> "

Function Signature

function nSerialReader(idx, files, ansArray)

Example Input

let ansArray = []; let files = ["file1.txt", "file2.txt", "file3.txt"]; nSerialReader(0, files, ansArray);

Example Output

ansArray = [ "content -> content of file1.txt", "content -> content of file2.txt", "content -> content of file3.txt" ]

Example Explanation

The function reads one file at a time. Once the current file finishes reading, the next file is processed using recursion until all files are read.

       function nSerialReader(idx, files, ansArray) {

           if (idx === files.length) return; // base case

           fetchByCb(files[idx], function (data) {
               ansArray.push("content -> " + data);

               // read next file AFTER current finishes
               nSerialReader(idx + 1, files, ansArray);
           });
       }
