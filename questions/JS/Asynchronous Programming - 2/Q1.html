Problem Description

Complete the function twoSeries(file1, file2, ansArray), which takes two file names and an array as input.

The files must be read serially using the provided fetchByCb(fileName, callback) function.

Requirements

  • Both files must be read one after the other (not in parallel)
  • Add the content of both files into ansArray
  • After reading both files, append the string "All files have been read" to the array

Function Signature

function twoSeries(file1, file2, ansArray)

Input Format

let ansArray = []; twoSeries("FILE 1", "FILE 2", ansArray);

Output Format

The ansArray should contain the contents of both files in order, followed by a completion message.

Example Output

ansArray = [ "content : FILE 1", "content : FILE 2", "All files have been read" ]

Example Explanation

The first file is read using fetchByCb. Once completed, the second file is read. After both files are processed, the final message is added.

        function twoSeries(file1, file2, ansArray) {
           fetchByCb(file1, function (data1) {
               ansArray.push(data1);

               fetchByCb(file2, function (data2) {
